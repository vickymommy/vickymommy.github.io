三、各功能區詳解

3-1 心情日誌（文章）

這個區在做什麼？ 顯示所有文章（包含從方格子自動同步進來的 + 在後台手動新增的）。你可以查看文章狀態、新增獨家文章、修改分類或標籤。

⚠️ 方格子同步來的文章，不要在這裡改內文。要改內文請去方格子改，網站會自動更新。

新增獨家文章：步驟

  1. 點左側「心情日誌（文章）」
  2. 右上角點綠色「Add an entry」
  3. 依序填寫欄位（見下表）
  4. 右上角按「Save」
  5. 約 1～2 分鐘後，網站上就能看到這篇文章
欄位必填？說明範例
標題✅文章標題給媽媽的 AI 學習起點
發布日期✅選一個日期2026-06-13
分類✅從下拉選一個AI 學習應用
封面圖建議填上傳圖片，建議 16:9、至少 800px 寬點 Upload 上傳
摘要✅顯示在文章卡片，1～2句話這篇文章分享了我第一次用 AI…
標籤可選關鍵字，可多個AI、媽媽成長
原文連結（方格子）❌留空獨家文章不填；填了會被同步覆蓋（空白）
閱讀分鐘數可選預估5
內文✅文章正文，可用編輯器工具列排版（正文內容）

修改現有文章：步驟 點「心情日誌（文章）」→ 找到文章點「Edit」→ 修改欄位 → 按「Save」

上傳封面圖片：在文章編輯頁點「封面圖」旁的「Upload」，選擇圖片檔（jpg/png/webp/gif）。建議寬度 800px 以上、比例接近 16:9；檔名用英文或數字（例如 cover-ai-2026.jpg）。

3-2 分享天地（每週精選）

這個區在做什麼？ 系統每天自動抓取各網站的新文章/工具，放在這裡等你審核。覺得值得推薦的，填上「Vicky 心情分享」，設定週次後發布，前台就會出現。

💡 系統每天凌晨 2 點抓一次，候選可能一次累積很多。挑你自己真的覺得有用的就好。

✅ 要發布的：

  1. 填寫「Vicky 心情分享」— 這是網站的靈魂，要告訴讀者「Vicky 親自試過，覺得這個有用，因為…」
  2. 把「狀態」改成「已發布」
  3. 填「發布週次」— 格式 2026-W25；同週審核通過的填同樣週次，前台會整理在同一區塊
  4. 按「Save」

❌ 不想用的： 把「狀態」改成「不採用」，或不管它

自己手動新增精選： 按「Add an entry」→ 填標題、連結、來源、類型 → 一定要填「Vicky 心情分享」→ 狀態選「已發布」→ 填發布週次 → 按「Save」

💡 YouTube 影片也能加入精選！在「連結」欄位填入 YouTube 網址即可。

3-3 每週精選來源管理

設定系統自動抓取的網站來源，可自行新增、暫停、刪除。新增後隔天凌晨 2 點才開始抓。

新增來源：點「每週精選來源管理」→「Add item」→ 填來源名稱、RSS 網址、類型、每次抓幾篇（建議3~5）、啟用勾選 → Save

暫停來源：點進該來源 → 取消「啟用此來源」勾選 → Save

3-4 社群交流圈（設定）

管理社群連結、YouTube 影片清單、介紹文字與圖片。新增影片：「影片清單」→「Add item」→ 填 YouTube 影片 ID（網址 v= 後面那串字）與標題 → Save

3-5 課程（設定）

管理課程名稱、說明、大綱、報名連結，改完按 Save。

3-6 Actions（手動觸發同步）

方格子同步平時每天凌晨 2 點自動執行。想立刻同步：

  1. 開啟 github.com/vickymommy/vickymommy.github.io/actions
  2. 左側找「daily_sync」點它
  3. 右側點「Run workflow」→「Run workflow」
  4. 等 3～10 分鐘後確認網站
⚠️ 不要連續觸發多次。

四、文章是怎麼進來網站的？（重要！先看這裡）

網站文章有兩條路，先搞懂這個，後面規則就都合理了：

路線 A：方格子自動同步（你不需要做任何事）— 每天凌晨 2 點自動抓新文章、含圖片。

路線 B：後台直接新增（適合網站獨家內容）— 例如網站公告、課程心得。

為什麼有這個區分？（選讀）方格子有 RSS feed，讓 GitHub 上的自動程式定期抓新文章、自動更新網站，玲玲不用多做事。兩條路靠文章的「來源」欄位區隔：有方格子網址 → 自動同步管；空白 → 後台管，同步不會動它。

❌ 不要在 PagesCMS 後台修改「從方格子來的文章」的內文——下次同步會被方格子版本覆蓋。
✅ 要改文章，就去方格子改 → 下次同步自動帶過來。

五、玲玲的每週工作建議

每天不用做什麼：系統自動同步，方格子發文隔天自動出現。

建議每週做一次：

  1. 審核每週精選候選（15~30分鐘）：「分享天地」逐筆看過，值得的填心得、改已發布、填週次
  2. 查看文章是否正常（可選，5分鐘）：「心情日誌」確認最新文章已同步
  3. 有新影片/活動才做：分別到「社群交流圈」「課程（設定）」更新

八、常見問題與緊急狀況

Q：不小心在後台改了方格子文章內文？ A：不用太擔心，下次同步方格子版本會蓋回來。想保留先截圖。

Q：每週精選候選清單沒有新項目？ A：可能是某個RSS來源失效，去「每週精選來源管理」確認，或聯絡Justin。

Q：存完一直沒看到更新？ A：等超過5分鐘去GitHub Actions查看，截圖傳給Justin。

Q：方格子發文隔天網站還沒出現？ A：先確認方格子文章是公開發布非草稿，若已公開仍沒出現找Justin。

Q：不小心刪掉文章？ A：可以救回來，GitHub有版本歷史，告訴Justin是哪篇。

Q：可以先存草稿嗎？ A：目前按Save即發布。每週精選可先維持「待審」，文章可填未來日期。

Q：圖片上傳失敗？ A：確認不超過5MB、檔名不含中文或特殊符號。

Q：按鈕是英文？ A：Save=儲存、Edit=編輯、Delete=刪除、Add an entry=新增一筆、Add item=清單新增一項、Cancel=取消。

九、GitHub 兩步驟驗證設定（2FA）

為什麼要做？ 開啟後登入除了密碼還要多驗證一步，讓帳號更安全。

準備工作：手機安裝 GitHub Mobile app（App Store/Google Play搜尋「GitHub」下載並登入），或準備可收簡訊的手機。

設定步驟：

  1. 電腦瀏覽器開 github.com，用帳號（vickytsai927）登入
  2. 點右上角大頭照 →「Settings」
  3. 左側「Password and authentication」，往下找「Two-factor authentication」
  4. 點「Enable two-factor authentication」
  5. 選擇驗證方式：

✅ 方法A：GitHub Mobile（推薦）：選「GitHub Mobile」→ 手機App確認 → 完成。日後登入手機收通知按「確認」即可。

✅ 方法B：SMS簡訊（備用）：選「SMS/Text message」→ 輸入手機號（+886開頭）→ 輸入驗證碼 → 完成。

6. 務必截圖/記錄「Recovery codes（備用碼）」，存放安全的地方。手機遺失或收不到驗證時可用來登入。

完成後：「Two-factor methods」旁會顯示「Configured」。

遇到問題：找不到Settings→確認已登入；沒收到簡訊→等1分鐘再試或改用Mobile方式；其他問題聯絡Justin。

設定完成後請通知 Justin 確認 ✅
